A personal calendar assistant

Less calendar admin.
More knowing what’s on.

Espejo helps its owner turn plans from conversations and messages into calendar suggestions.

It checks selected Google calendars for existing events, prepares a proposal, and presents it privately in Telegram. The owner can accept, dismiss or request changes. Creating or changing a calendar event requires approval of the specific proposal.

What Google Calendar access is for

Espejo reads the calendar list and events on configured, owned calendars to detect existing plans and avoid duplicates. It can create events and update supported individual events on the selected calendar after approval. It does not invite guests or send attendee updates.

For personal use

Espejo is a private, self-hosted tool for its operator. This website provides information about the integration; it has no public registration or Google sign-in.
